# 9/8 · SF05 문서의 현재 계약 정리

작성 기준: 개발 검토 `064509f`, 선행 안정화 명세 `8c4a3f1`. 이 단위는 RV03의 문서 충돌을 수정하며 앱 소스·테스트·기존 검토 증거를 변경하지 않았다. RV01/RV02의 코드 수정 완료와 새 전체 시험 수는 이 담당 기록에서 판정하지 않고 [안정화 명세·결과](../../../docs/2026-09-08-review-fixes.md)를 따른다.

## 원인과 수정 원칙

같은9/8에 기능이 여러 차례 확장되며 ‘최신’ 단락이 누적됐고, 앞 단계의 스키마·다음 개발 목록이 현재형으로 남았다. 상단에 또 다른 최신 단락만 붙이는 방식으로 해결하지 않고, 현재 계약 본문을 교정하고 당시 결과/제안을 별도의 역사 절로 옮겼다. [현재 상태표](../../../docs/2026-09-08-remaining-work.md)를 범위·형식·다음 작업의 정본으로 사용한다.

## 코드 대조와 검증 범위

- `LocalTrainingStore.decodeEnvelope/encodeEnvelope`:1~6 읽기, 복원 세대6→추가 처방5→고급4→기본3 쓰기 우선순위를 직접 확인했다.
- `AdminWorkspace.toJson/exportCatalog`: 원문/카탈로그/이력의 추가 처방 또는 보관/이력은4, 고급3, 기본2이며 내보내기는 배포 대상의 처방으로3/2/1을 고름을 확인했다.
- `LocalSettingsStore`와 `AppSettings`:1/2 읽기·2 쓰기, 기본 휴식null 또는1~3600, 자동 시작false와 성공 적용값을 확인했다.
- `training_insights.dart`: 세션 전체 필수 완료/초안 검사, 해당 운동 필수·작업·비AMRAP, 고정 일치/범위 안 실제 반복, 미래 작업·비AMRAP 감량을 확인했다. 실제 수행일을 기준으로 정책을 바꾸지 않았다.
- `DetailedBulkField`: repetitions/repetitionsMax/rir/restSeconds/fixedKg/kind의6개를 확인했다.
- 수정한 문서의 로컬 링크 대상과 `git diff --check`를 검사했다. 외부 URL·기기 실행·스토어 정책을 새로 검증한 작업은 아니다.

이번 단위에서 Flutter시험/Simulator/실기기/내부 네이티브 앱을 실행하지 않았다. 공동 작업의 코드 수정과 최종 자동 시험은 루트 통합 결과로 따로 기록한다. 현재 링크 검사 결과는 [documentation-links.json](documentation-links.json)을 따른다. 검사 후 루트가 상태/결과 문서를 마무리할 수 있으므로 최종 전체 링크 검사는 통합 단계에서 재실행한다.

## 남는 한계

실제 기기 파일 공급자·강제 종료/재실행·접근성·서명/설치는 미검증이다. SF-D01 저장 실패와SF-D03 지연은 실제 기기용 주입 자료가 없으면 자료 미준비로 남긴다. 상품/결제/지원/원격 운영과 자동 훈련 엔진의 정책은 이번 문서 정리로 확정하지 않았다. 원문 리서치·구버전 시험 로그와 기존 검토 보고서는 수정 전 이력으로 유지한다.
