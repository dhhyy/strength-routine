# 9/7 초기 공개 프로그램 후보

조사일: 2026-09-07. 사용자 추가 답변: **“공개 프로그램을 조사해 후보를 제안해줘”**. 이 문서는 후보 비교이며, 특정 프로그램의 채택·앱 수록·배포 승인은 아직 확정되지 않았다.

공식 저자·운영자가 공개한 원문을 확인했다. 아래 대상·빈도·처방 방식은 원문 설명의 요약이다. 효과를 독립 검증했다는 뜻이 아니며, 전체 운동표·설명문·이미지·유료 자료를 복제하지 않았다. 세 후보 모두 **제3자 앱 재배포 라이선스는 확인되지 않았다(UNKNOWN)**. 공개 열람 또는 개인 이용용 무료 배포와 앱 콘텐츠 수록 권한을 구분한다.

세 후보는 입문용 구조 비교에 초점을 두었다. 중급용 고정 기간 프로그램을 원한다면 [The Strength Athlete의 공식 Freebies](https://www.thestrengthathlete.com/freebies)에 TSA Intermediate 및 Beginner 원본 자료가 공개되어 있는 것까지 확인했다. 첨부 워크북의 처방·정확한 버전·재배포 권한은 이번 조사에서 확인하지 않아 동등한 검증 완료 후보로 올리지 않았다.

## 우리 제품과 연결되는 판단

1. **화면·저장 구조를 먼저 완성할 때는 Stronglifts 방식이 가장 단순한 비교 기준이다.** 이는 개발 복잡도에 대한 판단이며 사용자에게 가장 효과적인 훈련이라는 순위가 아니다. 원작 채택 결정은 하지 않았다.
2. **완성된 기간형 프로그램과 반복 규칙형 프로그램을 구분해야 한다.** 세 후보를 모두 일률적인 4주·동일 세트 데이터로 변환하면 원문 의미가 달라진다. 현재 사용자 요구에 맞추려면 채택 후보의 구체적 버전·기간·세션을 확정해야 한다.
3. **최근 기록의 역할은 프로그램마다 다르다.** 수행 중량, rep max, training max를 하나의 숫자로 취급하지 않는다. 후보가 정해지기 전 공통 e1RM 공식이나 TM 비율을 코드 기본값으로 선택하지 않는다.
4. **필수 기록이 없는 운동을 임의 삭제하지 않는다.** 선택한 프로그램의 필수 기록 목록을 보여주고 필요한 입력을 받는다. 보조 운동의 시작 중량 처리도 프로그램 데이터 정책과 함께 결정한다.
5. **버전과 출처를 보관한다.** 프로그램 ID·작성자·원본 URL·확인일·원본 버전·수록 권한 상태와 사용자 시작 당시 스냅샷을 분리한다. 원문 업데이트와 사용자가 수행한 기록을 함께 덮어쓰지 않는다.

## 사용자에게 제시할 선택 설명

- **Stronglifts 5×5:** 단순한 A/B 순환과 수행 기반 중량 증가를 먼저 다루고 싶을 때.
- **GZCLP:** 리프트별 역할·AMRAP·진행 단계를 갖춘 유연한 구조를 원할 때.
- **5/3/1 for Beginners:** training max와 비율 기반 처방을 중심에 두고 싶을 때.

다음 인터뷰는 **첫 수록 후보 또는 고정 기간형 후보 추가 조사 방향**을 고르는 단계다. 선택 후 해당 버전의 총기간·운동/세트·처방 범위·필수 기록·콘텐츠 수록 조건을 검토한다. 그동안 프로그램 목록·상세·빈 상태·시작 설정·저장 계약은 특정 원작 없이 개발할 수 있다.

## 확인 범위

- 세 후보의 공식 원문 URL 접속과 본문 확인 완료.
- 원저자 GZCLP의 주 3회 예시를 기준으로 했으며, 타 서비스의 주 4회 변형과 혼합하지 않았다.
- 훈련 중량 수치, 자동 증량 공식, 고정 주차를 우리 앱의 확정값으로 채택하지 않았다.
- 실제 앱 설치·운동 실행·프로그램 전체 수록·유료 자료 구매·저자 연락 없음.
