# 9/8 · 구현 완료 범위와 남은 운영 확인

최신 요청은 “모두 문서 작성 후, 기능 구현해줘”이며 직전에 안내한 여섯 로컬 기능 묶음을 [선행 명세](2026-09-08-local-completion.md)로 구체화했다. 이전 고급 처방252개는 당시 기준이며 이번 결과로 재사용하지 않는다. 최신 전체 검증은 [로컬 완성 보고서](2026-09-08-local-completion.md#10-구현검증-기록)에 기록한다.

**최종 검증:** 전체349개 테스트·정적 분석·iOS 기기 대상 빌드 성공. 실제 기기와 Simulator는 실행하지 않았다.

## 이번에 연결한 여섯 기능

|---|---|---|
| 운동 기록 백업·복원 | OS 파일 선택/저장, 무결성/버전 검사, 현재·후보 비교, 교체/취소, 복구본, 손상 로컬 원본 보존, 타이머 세대 분리 | [LC01](2026-09-08-local-completion.md) |
| 남은 일정과 놓친 운동 | 미래 날짜 변경·전후 검토·원자 저장, 기록이 있는 세션 보호, 놓친 운동 전체 접근 | [LC02](2026-09-08-schedule-previous.md) |
| 이전 실제값 복사 | 같은 프로그램/버전/종목/세트의 출처 확인, 기존 입력 교체 확인, 원래 단위·중량·반복만 초안 복사 | [LC03](2026-09-08-schedule-previous.md) |

이전의 프로그램5개 선택→개인화→운동 입력/초안/완료/마감→로컬 복원, 기록 달력·추세·D5/되돌리기, 검색·습관·기본설정, 관리자 상세 작성, 휴식·템포·슈퍼세트·AMRAP, FAQ·구독 준비 안내와 랜딩5개 시안도 유지한다. 이번 작업은 동일 기기 앱 기능과 내부 관리자 도구의 확장이며 공개 운영 완료를 뜻하지 않는다.

## 새 저장 계약

- 카탈로그 읽기1~3, 새 반복범위/세트종류가 있으면3, 이전 고급 처방만 있으면2, 기본은1.
- 관리자 읽기1~4, 새 처방/보관/버전 이력이 있으면4, 이전 고급 초안은3, 기본정밀초안은2.
- 운동 읽기1~6, 기본3/고급4/추가처방5, 백업 복원 이후에는6과복원세대를 유지한다.
- 설정 읽기1/2·쓰기2, 타이머 처방출처1/사용자출처2, 운동 백업형식1.
- 기본5개 번들파일은 그대로이며 과거 계획 스냅샷에 새 프로그램을 소급하지 않는다.

## 기능 범위 밖의 별도 개발·운영

| 항목 | 현재 경계 | 필요한 후속 |
|---|---|---|
| OS 알림·워치·소리·진동 | 앱 내 타이머까지 구현 | 플랫폼 권한·백그라운드/잠금화면 동작 구현과 실기 확인 |
| 원격 관리자/콘텐츠 배포 | 내부 관리자 빌드·JSON내보내기 | 운영 서버/인증·권한·원격 버전배포를 채택할 때 별도 구현 |
| 실제 결제 | 구독 운영안과 준비안내 | 가격/혜택/플랫폼상품·거래검증·권한·복원·갱신/만료/환불 연결 |
| 실제 문의 접수 | 로컬 FAQ | 지원 주소/접수채널·운영정책과 전송/답변 구현 |
| 여러 기기 동기화 | 운동 파일 수동 이동 가능 | 계정/동기화/충돌정책·서버 구현 |
| 자동 훈련 엔진 | 명시 처방과 D5 | e1RM·자동진급·AMRAP자동증량 등 정책과 별도 검증 |
| 전체 앱 백업 | 운동 데이터만 포함 | 습관/설정/관리자 파일까지 묶는 다중파일 세대 트랜잭션 |

다중 트레이너 등록·승인·정산은 사용자 지시로 제외한다. 현재 관리자는 로그인된 웹 관리자가 아니라 내부 Flutter앱 진입점이다. 카탈로그 보관은 다음 JSON내보내기에서 제외하는 동작이며 사용자 앱의 원격 삭제가 아니다. 이런 별도 기능도 코드 개발은 가능하지만 이번 여섯 로컬 기능이 구현됐다는 이유로 운영 연결까지 끝났다고 표현하지 않는다.

## 실제 기기와 출시 확인

실제OS파일공급자·외부브라우저·키보드·접근성·프로세스종료/재실행, 서명/설치, 운영자 프로그램·가이드/D5검토와 최종랜딩 선택/공개배포가 남아 있다. [추가 기기시험 LC-D01~14](2026-09-08-device-test-guide.md)에 실제 버튼 순서·기대결과·미실행칸을 남겼다. iOS서명 없는 device대상 빌드와 headless위젯 테스트를 실제기기 검증으로 계산하지 않는다. 사용자 재요청 전 Simulator는 실행하지 않는다.

## 집에서 시안을 확인할 때

같은 컴퓨터라면 서버 실행 상태에서 [비교 페이지](http://127.0.0.1:4175/landing/concepts/)를 연다. `127.0.0.1`은 접속하는 컴퓨터 자신이므로 다른 컴퓨터에서 현재 서버로 연결되는 공유 주소가 아니다.

다른 컴퓨터라면 프로젝트 파일을 옮기고 [시안 실행 안내](../landing/concepts/README.md)에 따라 앱 루트에서 정적 서버를 실행한다. `landing/concepts/`만 옮기면 상위 상태 모듈·토큰·프로그램·폰트가 빠지므로 앱 폴더 구조를 보존한다. 현재 저장소에는 Git 원격이 등록돼 있지 않고 이번 작업은 로컬 커밋까지 완료된 상태다. 외부 배포·원격 푸시는 수행하지 않았다.
