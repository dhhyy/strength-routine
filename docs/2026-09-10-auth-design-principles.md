# 인증·온보딩 디자인 원칙 (2026-09-10)

Console v2 토큰(`lib/tokens.dart`)은 유지한다. 이 문서는 **가입·로그인·온보딩**에만 적용하는 상호작용·카피 원칙이다.  
제품 결정·Supabase 설정은 [auth-kakao-flow](2026-09-10-auth-kakao-flow.md)를 본다.

참고: [토스 가입 화면](https://toss.tech/article/toss-signup-process), [최소 입력](https://toss.tech/article/4-ways-for-minimum-input), [인터랙션](https://toss.tech/article/interaction), TDS Agreement.

---

## 1. 한 화면에 할 일 하나

- 한 화면의 주 행동(Primary)은 **하나**다.
- 소개 슬라이드 → `다음` / 마지막 허브 → `간단하게 가입하기` / 로그인 화면 → `카카오로 계속하기`.
- 보조 행동(로그인하기, 뒤로)은 텍스트 링크로 낮춘다. 같은 시각 무게의 CTA 두 개를 나란히 두지 않는다.

## 2. 왜인지 한 줄

- 정보를 받기 전, **왜 이 화면인지** 한 문장을 둔다.
- 예) 로그인: 「이미 만든 계정으로 이어서 훈련해요.」
- 예) 가입: 「약관에 동의한 뒤 카카오로 바로 시작해요.」
- 「본인인증」「금융 보안」 등 이 제품에 없는 신뢰 카피는 쓰지 않는다.

## 3. 클릭·입력을 줄인다

- 단일 선택·자릿수가 정해진 입력은 **확인 CTA를 생략**하고 완료 시 다음으로 가도 된다(해당 필드가 생길 때).
- 숫자 필드는 **숫자 키보드**, 진입 시 **autofocus**.
- CTA는 키보드에 가리지 않게 한다(`viewInsets` 반영).
- 로딩은 새 화면이 아니라 **CTA 자리 morph**(라벨 → 인디케이터).

## 4. 약관은 부드럽게, 분명하게

- **필수 / 선택 분리.** 마케팅은 기본 해제.
- 전체 동의는 필수만 묶는다(선택 마케팅을 강제로 켜지 않는다).
- 체크 변화는 짧은 easeOutCubic(soft). 과한 bounce 금지.
- 필수 미체크 상태로 진행 시 **좌우 흔들림**으로 피드백(비활성 탭 피드백과 동일한 계열).

## 5. 전환·모션

- 페이지·라우트: **~300ms, easeOutCubic**.
- 모션은 **피드백·인과**가 있을 때만. 장식용 루프·글로우 과다는 넣지 않는다.
- 정적 UI로 전달 가능한 내용은 모션으로 과장하지 않는다.

## 6. 카카오만, 브랜드 예외

- IdP는 카카오만. 화면 안에 Apple/Google/이메일을 나란히 두지 않는다.
- 카카오 CTA는 공식 노랑(`#FEE500`) + 짙은 글자. 앱 accent(시안) CTA와 역할을 섞지 않는다.
  - 가입 허브 Primary = 앱 accent「간단하게 가입하기」
  - 로그인/가입 실행 = 카카오 노랑「카카오로 …」

## 7. 세션과 화면 게이트

- 유효 세션이 있으면 **인트로·로그인·가입을 다시 보여 주지 않는다.**
- 세션이 없으면 홈에 들어가지 않는다(가입 강제).
- 「건너뛰기」는 홈 스킵이 아니라 **인증 허브(마지막 장)** 로만 이동한다.

## 8. 복사하지 않는 것 (토스 ≠ KYC)

- 주민번호·통신사·실명 본인확인·ARS
- 가입 직후 앱 PIN·보안키패드
- 역순 실명 필드 스택(금융 묶음용 패턴)
- 권한 요청 연속 폭격

## 화면별 적용

| 화면 | Primary | 원칙 포인트 |
|------|---------|-------------|
| 소개 1–4 | 다음 | 한 일, 짧은 전환 |
| 소개 5 (허브) | 간단하게 가입하기 | 로그인하기는 보조 텍스트 |
| 가입 | 카카오로 가입하기 | 약관 → 카카오, 필수 흔들림 |
| 로그인 | 카카오로 계속하기 | 맥락 한 줄, CTA morph |

## 검증

- 세션 없음: 소개 → 허브 → 가입/로그인만 진입. 홈 직접 진입 불가.
- 세션 있음: 콜드 스타트 시 홈.
- 로그인하기 탭 → `LoginScreen` 표시.
- 위젯 시험: `test/widget_test.dart`의 인증 게이트 시나리오.
